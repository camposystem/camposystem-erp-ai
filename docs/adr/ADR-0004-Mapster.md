
# ADR-0004 – Adoção do Mapster
- **Status:** Aceita
- **Data:** 27/07/2026
- **Autor:** Alexandre de Campos
---

## Decisão: 

Utilizar Mapster para o mapeamento entre DTOs, Commands e Entities.

## Justificativa:

- Projeto totalmente open source.
- Alto desempenho.
- Baixo overhead.
- Fácil configuração.
- Adequado para aplicações Minimal API.

## Alternativa rejeitada

AutoMapper

Motivo:

- Maior overhead
= Maior custo de configuração em relação ao Mapster para este projeto.
