
# AUDITORIA

__RF08__ — Registro de auditoria
O sistema deve registrar operações de negócio definidas como auditáveis.

__RF09__ — Identificação da operação
O registro deve armazenar usuário, operação, entidade e data/hora.

__RN13__ — Rastreabilidade
Toda operação definida como auditável deve possuir informações
suficientes para identificar quem realizou a operação e quando.
