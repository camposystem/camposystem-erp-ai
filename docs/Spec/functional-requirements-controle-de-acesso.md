# CONTROLE DE ACESSO

__RF05__ — Autenticação
O sistema deve permitir autenticar usuários.

__RF06__ — Gerenciamento de permissões
O sistema deve permitir associar permissões aos usuários/perfis.

__RF07__ - Autorização
O sistema deve verificar a permissão necessária para uma operação.

__RN12__ - Permissão obrigatória
Uma operação protegida somente poderá ser executada por usuário
que possua a permissão correspondente.
